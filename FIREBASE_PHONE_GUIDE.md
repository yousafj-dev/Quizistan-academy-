# Firebase Setup — Phone Guide (Roman Urdu)

**Waqt:** ~10 minute | **Zaroorat:** Sirf mobile + Google account

Tumhe sirf **project banana** aur **ek file bhejni** hai. Baqi sab (app me lagana + final build) main karunga.

## Steps

**1.** Mobile browser me kholo: **firebase.google.com** → **"Go to console"** dabao → apne Google account se sign in karo (wahi account jo app ke liye use karna hai).

**2.** **"Add project"** ya **"Create a project"** dabao.

**3.** Project ka naam likho: **Quizistan Academy** → **Continue** dabao.

**4.** Google Analytics ka puche to **Enable** kar do (ek tap) → **Continue** → **Create project**. Thoda wait karo, phir **Continue** dabao.

**5.** Ab project khul jayega. **Android wala icon** dabao (🤖 "Add an app" me).

**6.** Form me ye likho:
- **Android package name:** `com.quizistan.quizistan_academy` (bilkul yehi, ek harf ka farq na ho)
- **App nickname:** Quizistan Academy
- SHA-1 khali chhor do (zaroori nahi)
→ **"Register app"** dabao.

**7.** Agli screen par **"Download google-services.json"** dabao — file phone me download ho jayegi.

**8.** Ye file **mujhe bhej do** (chat/WhatsApp me attach kar dena). Bas — tumhara kaam khatam! ✅

## Yaad rakhne wali baatein
- Package name **exact** hona chahiye: `com.quizistan.quizistan_academy`
- google-services.json milte hi main use app me laga ke **final release build** bana dunga.
- Agar kahin atak jao to screenshot bhej dena, main bata dunga.
